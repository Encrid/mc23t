# .toolchain/tools/c23.py

`c23.py` finds the older spellings of C in the code of the project.
`docs/contributing/coding_style.md`, *C23* gives each older spelling and its newer spelling.
`c23.py` reads the same files as `.toolchain/tools/style.py`: those of `tests` too, and none of `third_party`. It does not read the comments and the strings.

```sh
python .toolchain/tools/c23.py [--root <folder>]
```

## Exceptions

`[[c23.exception]]` of `.toolchain/project.toml` lets the files of a `path` keep their older spellings.
An example is a file that a third-party build compiles with an older standard.
The `path` can contain `*`, and `why` states the reason: `.toolchain/docs/project.toml.md`, *[[c23.exception]]*.
An exception with no `why` is a fault: `.toolchain/project.toml:1: the exception for '<path>' states no reason`.
An exception that excuses no older spelling is a fault: `.toolchain/project.toml:1: the exception for '<path>' excuses nothing`.

## Output

Each older spelling is a fault: `<path>:<line>: <older>  ->  <newer>`.
Its faults follow the paths, then the older spellings, then the lines.
The output follows `.toolchain/docs/shared.py.md`, *The report of a check*.

## Functions

| Function | Result |
| --- | --- |
| `main()` | Reads the files, and writes each older spelling. |
| `excused(paths, faults)` | Gives the faults that no exception excuses, and the faults of the exceptions. |
